= Independent Example
:toc:

The `example` directory is a standalone Gradle build. It does not include Keb
source projects and does not use a composite build.

[source,text]
----
example
├── ui        Bun + Vite + React + Material UI
└── testing   Kotlin + JUnit 5 + published Keb artifacts
----

The testing module resolves:

[source,text]
----
org.openprojectx.test.keb:keb-core:<kebVersion>
org.openprojectx.test.keb:keb-junit5:<kebVersion>
----

from the repository-local Maven directory at `build/example-maven`.
`example/gradle.properties` supplies the default version for local use. CI
passes the root project version explicitly so release version changes cannot
leave the consumer on an older snapshot.

== Run the complete example

From the repository root:

[source,shell]
----
./gradlew publishExampleArtifacts
./gradlew -p example check
----

The workflow:

. publishes the current Keb modules locally;
. runs `bun install --frozen-lockfile`;
. type-checks and builds the Vite application;
. starts `vite preview`;
. runs the Keb/JUnit journeys in Chromium;
. stops the preview server.

Snapshot dependency caching is disabled in the consumer build so a republished
artifact is picked up immediately.

== Remote browser in Docker

The example can run the same journeys from the host JVM against a Playwright
server in `mcr.microsoft.com/playwright:v1.62.1`:

[source,shell]
----
./gradlew publishExampleArtifacts
./gradlew -p example :testing:remoteTest
----

The task uses `example/compose.yaml`, waits for the browser server, forwards
`keb.remoteEndpoint=ws://127.0.0.1:3000/`, and tears the container down after
the tests. It also disables local Playwright browser downloads. The browser
reaches Vite through `http://host.docker.internal:4173`; the Compose
configuration installs the Linux host-gateway mapping and adds that hostname
to `NO_PROXY`. Docker Compose v2 and access to the Microsoft and npm registries
are required on the first run.

== UI development

[source,shell]
----
./gradlew -p example :ui:bunDev
----

The UI is served at `http://127.0.0.1:4173`.

Bun uses the calling environment's `.npmrc` or `bunfig.toml`. The example does
not override the npm registry and commits `bun.lock` for repeatable installs.

== UI coverage

The Material UI application includes:

* application bar, drawer, breadcrumbs, avatars, badges, lists, and tooltips;
* text, email, password, date, select, autocomplete, radio, checkbox, switch,
  and slider inputs;
* buttons, icon buttons, floating action buttons, links, menus, and pagination;
* cards, chips, alerts, snackbars, dialogs, progress indicators, and skeletons;
* tabs, accordions, tables, ratings, responsive layout, and theme switching.

The tests model the profile form, component playground, and team table as Keb
modules. Locators primarily use accessible roles, labels, and visible names.
